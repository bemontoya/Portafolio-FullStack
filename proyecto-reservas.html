Sistema de Reservas & Gestión (Backend API)

2026 Java | Spring Boot | MySQL | Docker | Postman

API RESTful robusta orientada a la gestión automatizada de reservas y servicios. Desarrollada con arquitectura de microservicios, integrando almacenamiento en base de datos relacional y contenedorización para entornos de despliegue consistentes.

Arquitectura Backend

Construido con Java y Spring Boot, implementando controladores RESTful, manejo de excepciones global y seguridad en endpoints.

Base de Datos & Docker

Persistencia en MySQL administrada mediante JPA/Hibernate y contenedorizada con Dockerfile para facilitar su despliegue.

Testing & Docs

Validación de endpoints y consumo de servicios mediante Postman, con documentación interactiva expuesta en Swagger.
